# Light-Dark-Mode-
# 🌗 Dark / Light Mode Toggle

## 📌 Project Description
This project is a modern and interactive Dark/Light theme toggle switch built using HTML, CSS, and JavaScript. It allows users to switch between light mode and dark mode with a smooth animation and visually appealing UI design.

The toggle switch includes dynamic color changes, hover effects, and an animated icon (moon/sun). The selected theme is stored using browser localStorage so that the user’s preference is saved even after refreshing the page.

---

## ✨ Features

- 🌙 Toggle between Dark and Light mode
- 🎨 Smooth color transition effect
- 💾 Saves user preference using localStorage
- ✨ Hover effects for better UI experience
- 🎯 Clean and responsive design
- 🔄 Animated toggle switch with icons

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox, Transitions, Gradients)
- JavaScript (DOM Manipulation, localStorage)
